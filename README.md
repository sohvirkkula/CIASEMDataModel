# A CIM-Based Data Model for Energy Flexibility in Multi-Agent Energy Management Systems

This repository contains the data model for the paper "A CIM-Based Data Model for Energy Flexibility in Multi-Agent Energy Management Systems". 

## Repository Contents

## Description
The repository contains the data model files, for the unified, CIM-based data model, developed within the CIASEM project. 

## Software 
The data model was developed using the CIMTool.
