# A CIM-Based Data Model for Energy Flexibility in Multi-Agent Energy Management Systems

This repository contains the data model for the paper "A CIM-Based Data Model for Energy Flexibility in Multi-Agent Energy Management Systems". The data model was developed within the CIASEM (Collaborative Intelligent Agents for Smart Energy Management) project, funded by Business Finland. 

## Description
In multi-agent energy management systems, energy flexibility relies on coordinated interactions among heterogenous distributed energy resources and system actions that adjust energy consumption and/or generation in response to varying external conditions. These interactions involve the exchange of structured information between agents, such as forecasts of flexibility potential, flexibility offers, and control instructions. However, differences in data models, standards, and system implementations create semantic interoperability challenges in the representation and exchange of these messages across agents. This paper presents a data model for energy flexibility in multi-agent energy management systems based on the Common Information Model (CIM). The model is derived using a scenario-based approach in which agent interactions and message exchanges form the basis for defining data requirements, including concepts, classes, attributes, and message structures. These requirements are mapped to CIM and used to define a set of profiles that capture energy flexibility-related interactions. The model is evaluated and iteratively extended using real-world message exchanges. The results demonstrate its relevance in realistic scenarios and provide a foundation for the incremental development and validation of interoperable, standards‑aligned data representations for evolving multi‑agent energy flexibility systems.
